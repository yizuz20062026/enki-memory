# Enki Portable

> Sistema multi-dispositivo de Enki — agent, web UI, memoria compartida.

## Stack
- Remote Agent: Node.js + Express, puerto 4000
- Web UI: Node.js + Express, puerto 3445
- Auth: Bearer token `20062026`
- LLM: Groq + DeepSeek V4 Flash (fallback)
- Sync: Syncthing
- Red: Tailscale (WireGuard)
- GitHub: `github.com/Yizuz20062026/enki-portable`
