# Workflow de Sesión

## Al INICIAR sesión
1. Leer `~/enki-memory/AGENTS.md` (si no está en contexto)
2. Leer `~/enki-memory/wiki/_INDEX.md`
3. Leer cápsulas relevantes al proyecto del día
4. Verificar sesiones pendientes en `sessions/`

## Durante la sesión
- Seguir workflow de 10 pasos para cada tarea
- Usar skills apropiadas según el dominio
- Guardar hallazgos en `raw/` si son nuevos

## Al CERRAR sesión
1. Actualizar `sessions/YYYY-MM-DD.md` con handoff
2. Crear/sintetizar notas nuevas de `raw/` → `wiki/`
3. Actualizar `_INDEX.md` si hay notas nuevas
4. Actualizar cápsulas si hubo cambios importantes
5. Push a GitHub si hay cambios en vault
