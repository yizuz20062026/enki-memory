# Lessons Learned

## Formato de lección
```markdown
# [L1-NNN] [Título]

**Fecha**: YYYY-MM-DD
**Proyecto**: [nombre]
**Severidad**: baja | media | alta | critica
**Estado**: active | invalidated

## Trigger
[Cuándo aplica esta lección]

## Acción
[Qué hacer differently]

## Verificación
[Cómo saber si funciona]
```

## Convenciones
- ID: L1-NNN (global secuencial)
- Al finalizar cada sesión importante → buscar lecciones
- Verificación semanal: ¿la lección evitó un error repetido?
- Si una lección se demuestra dañina → marcar `invalidated`
